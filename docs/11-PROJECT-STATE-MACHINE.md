# 11 — PROJECT STATE MACHINE (locked)

`DRAFT → PUBLISHED → RECEIVING_PROPOSALS → SHORTLISTING → NEGOTIATION → AWARDED → CONTRACTING → ACTIVE → ON_HOLD → COMPLETED → CLOSED`

Exceptions: CANCELLED (from DRAFT/PUBLISHED/RECEIVING_PROPOSALS/SHORTLISTING/NEGOTIATION), DISPUTED (from ACTIVE/ON_HOLD, snapshot active_status).

Edges: PUBLISHED→RECEIVING_PROPOSALS (auto on first publish window); SHORTLISTING→NEGOTIATION (customer); NEGOTIATION→AWARDED (select proposal); AWARDED→CONTRACTING (contract drafted); CONTRACTING→ACTIVE (contract accepted + first funding); ACTIVE↔ON_HOLD; ON_HOLD→ACTIVE/COMPLETED/DISPUTED; COMPLETED→CLOSED (retention+warranty ok); DISPUTED→restore/COMPLETED/CANCELLED per decision.

Milestone sub-flow: DRAFT→READY→FUNDED→IN_PROGRESS→SUBMITTED→(REVISION_REQUESTED→RESUBMITTED→SUBMITTED)*→APPROVED→RELEASE_PENDING→RELEASED | DISPUTED | CANCELLED. Funding = Order(type=MILESTONE_FUNDING) PAID moves READY→FUNDED; release moves funds to vendor payable via ledger.

Proposal: DRAFT→SUBMITTED→SHORTLISTED|REJECTED|WITHDRAWN→ACCEPTED. Quotation versions: DRAFT→SENT→APPROVED|REJECTED|EXPIRED (superseded via new version, never mutate approved). Contract: DRAFT→SENT→ACCEPTED (immutable; changes via Amendment versions).
