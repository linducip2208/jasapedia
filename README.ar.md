# جاسابيديا (Jasapedia)

**«كل الخدمات، منصة واحدة.»**

🌍 اللغات / Languages: [Indonesia](README.id.md) | [English](README.md) | **العربية**

منصة متكاملة لتجارة الخدمات: سوق إلكتروني للخدمات المنزلية والخدمات المهنية والخدمات الرقمية والمستقلين والفنيين الميدانيين وشركات الموردين والأعمال القائمة على المشاريع وطلبات عروض الأسعار (RFQ) والعقود والمشتريات المؤسسية — كل ذلك في منظومة واحدة.

## الحزمة التقنية (Stack)

| الطبقة | التقنية |
|---|---|
| الخادم الخلفي | Laravel 13 / PHP 8.3 / MySQL 8 / Redis |
| المصادقة | Sanctum (رموز API) + التحقق الثنائي TOTP للحسابات المميزة |
| الواجهة الأمامية | API أولاً (`/api/v1` — 223 مساراً) + واجهة ويب Blade/Tailwind — جاهزة لـ Flutter (تطبيقات العملاء والشركاء) |
| الزمن الحقيقي | أحداث Broadcast (متوافقة مع Reverb)، قاعدة البيانات مصدر الحقيقة، مع بديل استقصاء (polling) |
| المال | IDR كعدد صحيح، دفتر أستاذ مزدوج القيد غير قابل للتغيير، لقطة سعر لكل معاملة |
| الوسائط | `MediaService` مستقل عن القرص (`MEDIA_DISK`: public/s3/r2)، تحقق MIME حقيقي (finfo) + البايتات السحرية + حد الحجم |
| لوحة الإدارة | AdminLTE 4.9.1 (Bootstrap 5) كمدخل Vite معزول لـ `/admin` فقط |

## الميزات

### 1. واجهة المتجر للعملاء (ويب + API)

- **الصفحة الرئيسية الشاملة** — قسم البطل، 21 فئة، 6 بوابات دخول (ابحث عن خدمة / احجز فنياً / انشر طلباً / ابحث عن مستقل / أنشئ مشروعاً / للأعمال)، الخدمات الشائعة، كيف تعمل المنصة، قسم الثقة، ودعوات للتسجيل كمقدم خدمة أو شركة
- **الاستكشاف والبحث** — `SearchProviderInterface` (SQL مفعّل وجاهز لـ Meilisearch عبر `SEARCH_DRIVER`)، فلاتر الفئة/المدينة/السعر/التقييم، شرائح الفلاتر + لوحة جانبية للجوال، الترتيب، ونقطة اقتراحات
- **صفحة الخدمة 2.0** — معرض صور، لوحة شراء ثابتة، الجدول الزمني، رسم الطوارئ، الضمان، تقييمات موثقة، الحزم والإضافات
- **الدفع والطلبات** — عرض سعر بسلطة الخادم الخلفي (مثبّت في لقطة)، اختيار الموعد، لقطة العنوان مقفلة عند الحجز، ودعم الطلبات الطارئة
- **المدفوعات** — بوابة تجريبية (sandbox) على الويب، خطافات ويب موقعة وغير قابلة للتكرار، حماية من عدم تطابق المبلغ ومن الدفع المزدوج؛ محولات إنتاج لـ **Xendit** و**Midtrans** عبر `PAYMENT_DRIVER`
- **تتبع الطلب** — خط زمني حقيقي للحالة، تأكيد الإنجاز، تسجيل دخول بـ OTP (العميل يوثّق الفني)، وإلغاء وفق آلة الحالات
- **التقييمات** — تقييم واحد لكل طلب (للطلبات المكتملة فقط)، تقييم بأبعاد وفق إعدادات الفئة، ويُعاد حساب تقييم الشريك من المجاميع
- **المفضلة** — تبديل فريد في قاعدة البيانات للخدمات ومقدمي الخدمات، مع صفحة مفضلة
- **نشر الطلبات (RFQ)** — معالج نشر + مرفقات صور، موعد نهائي، رؤية (عام/مدعو)، ومقارنة عروض الأسعار وقبولها (نسخ مُصنّعة وموافقة غير قابلة للتغيير)
- **سوق المشاريع** — نشر المشاريع، استلام العروض، القائمة المختصرة/الإسناد، عقود بين طرفين، ومراحل: تمويل ← تنفيذ ← تعديل ← موافقة ← **صرف + قيد تلقائي في دفتر الأستاذ**
- **الدردشة** — محادثات لكل طلب ومباشرة، غير قابلة للتكرار (`client_message_id`)، إشعارات قراءة، مرفقات، وبديل استقصاء (جاهز للبث)
- **الإشعارات** — مركز إشعارات، عدّاد غير المقروء، تفضيلات لكل حدث×قناة، وسياسة الأحداث الحرجة
- **مركز الحساب** — لوحة رئيسية، الطلبات بحسب الحالة، الملف الشخصي، عناوين متعددة (إحداثيات)، والإشعارات
- **المدونة ونظام المحتوى** — مقالات المدونة، صفحات ثابتة (`/halaman/{slug}`)، وبلوكات الصفحة الرئيسية

### 2. مركز الشركاء ومقدمي الخدمات (ويب + API)

- **التسجيل والتحقق (KYC)** — تسجيل شريك (مستقل/فرد/شركة مورد)، تقديم KYC/KYB، المستندات، قرار التحقق من الإدارة + سجل تدقيق
- **منظمات الموردين** — منظمات شركاء وأعضاء بصلاحيات RBAC محددة النطاق (مالك/مدير/موزع/مالية/مدير مشاريع/فني)، المهارات، مناطق الخدمة (مدينة/نطاق)، وحسابات استلام الأموال
- **إدارة الخدمات** — إنشاء وتعديل الخدمات + رفع معرض صور (بتحقق MIME صارم)، الحزم، الإضافات، التسعير لكل نموذج (لكل وحدة/بالساعة/يومي/حزمة/ثابت)، وإيقاف/تفعيل
- **التوفر** — جداول أسبوعية، الحجوزات والإجازات، ومحرك مواعيد **آمن ضد التزامن** (قيد فريد + اختبارات تزامن)
- **صندوق الطلبات** — قبول/بدء/إنهاء الطلبات عبر آلة الحالات
- **التوزيع (Dispatch)** — عروض مهام بتقييم شفاف (التقييم، المسافة، معدل القبول)، أنماط مباشر-تلقائي/بث/تتابعي/يدوي/داخلي-الشركة، الأسرع قبولاً يفوز، ومدة صلاحية للعرض
- **عمليات الميدان (API `/field/*`)** — في الطريق ← وصل ← دخول بـ OTP ← بدء العمل ← أدلة قبل/بعد ← المواد ← **طلب تكلفة إضافية مُهيكل** (صلاحية 24 ساعة؛ نص الدردشة لا يغيّر المبالغ أبداً) ← تقديم الإنجاز
- **طلبات وعروض الأسعار** — استعراض الطلبات المفتوحة، وإرسال/تعديل عروض الأسعار (بنسخ مُصنّعة)
- **المشاريع والعقود** — تقديم/سحب العروض، بدء/تقديم المراحل، وسجلات العمل
- **المالية** — الرصيد، سجل التسويات، السحب (حجز آمن ضد التزامن، حد أدنى، ومنع الإكمال المزدوج)، وإضافة حسابات استلام
- **التقييمات** — قراءة التقييمات والرد عليها

### 3. جاسابيديا للأعمال (المؤسسات)

- **المنظمات المؤسسية** — فروع، إدارات، مراكز تكلفة، وموظفون بأدوار وحدود إنفاق
- **مصفوفة الموافقات** — حدود للمدير والمالية، اشتراط موافقة على الفئة، والفئات المسموحة
- **الموازنات** — تخصيص لكل مركز تكلفة لكل فترة مع تتبع الاستخدام
- **طلبات الخدمة** — موظف ← طلب ← موافقة على مستويين ← تحويل إلى طلب مع **الحفاظ على مرجع أمر الشراء (PO)**
- **لوحة المؤسسة** — ملخص الموافقات والطلبات والمصروفات

### 4. مركز قيادة الإدارة (`/admin`)

- **هيكل AdminLTE 4.9.1** (Bootstrap 5، وضع داكن عبر `data-bs-theme`)، معزول كمدخل Vite منفصل (`resources/css/admin.css` + `resources/js/admin.js`) — لا يُحمَّل Bootstrap أبداً في واجهة المتجر المبنية على Tailwind
- **لوحة مقاييس حقيقية** — إجمالي قيمة البضاعة (GMV)، حجم الطلبات، معدلات الإلغاء/النزاعات، عمولات دفتر الأستاذ، عمليات الميدان، و**فحص توازن دفتر الأستاذ**
- **الطلبات** — مراقبة كل الطلبات + سجل حالات غير قابل للتغيير
- **التحقق من مقدمي الخدمات** — دورة حياة KYC/KYB (قبول/رفض + ملاحظات + تدقيق)
- **المالية** — دورة حياة السحب (مراجعة/معالجة/إكمال/فشل) وفحص التوازن
- **النزاعات** — الحل بخيارات استرداد كلي/جزئي ← يُنفَّذ عبر دفتر الأستاذ
- **المستخدمون** — إدارة المستخدمين + سجل تدقيق للإجراءات الحساسة
- الوصول محكوم بصلاحيات دقيقة: `admin.*` / `audit.view` / `reports.view`

### 5. المالية ودفتر الأستاذ (نواة النطاق)

- **دفتر أستاذ مزدوج القيد** — Σ المدين = Σ الدائن يُختبر عند كل قيد + قيد شامل؛ التصحيح فقط عبر *قيود عكسية* (إضافة فقط — لا تُحذف صفوف المال أبداً)
- **العمولة** — لقطة غير قابلة للتغيير (فريدة لكل طلب)، والمعدل من الإعدادات
- **التسوية** — الإجمالي − الإضافي − العمولة = صافي المورد؛ حماية من التسوية المزدوجة
- **السحب** — تسلسل لكل شريك + محاسبة حجز، آمن ضد التزامن
- **الاسترداد** — الأهلية (≤ المدفوع − المسترد) + قفل تزامن؛ استردادات النزاعات تُنفَّذ في دفتر الأستاذ
- **التسوية المطابقة (Reconciliation)** — كشف الفروقات بين المدفوعات/التحويلات/دفتر الأستاذ
- جميع المبالغ **IDR كعدد صحيح** — لا فواصل عشرية للمال

### 6. الثقة والسلامة

- **KYC/KYB** — التقديم، قرارات المسؤول، وسجل تدقيق
- **النزاعات** — مسار مفتوح ← أدلة ← وساطة ← قرار، مع استرداد مدعوم بدفتر الأستاذ
- **مطالبات الضمان** — التحقق من النافذة وفق إعدادات الفئة
- **إشراف التقييمات** — الإبلاغ عن التقييمات/الرسائل، وحالة منشور/مخفي
- **سلامة الدردشة** — تحذير مشاركة بيانات الاتصال، الإبلاغ عن الرسائل، وحجب المستخدمين

### 7. النمو

- **الخدمات المتكررة** — جداول أسبوعية/شهرية، وتوليد تكرارات غير قابل للتكرار المزدوج
- **العروض وقسائم الخصم** — نوع نسبة/ثابت، حد أقصى للخصم، حد أدنى للإنفاق، حدود استخدام/لكل مستخدم، أول طلب فقط، قابلية التراكم، وحصة المورد
- **الإحالات** — أكواد حتمية، التأهيل، والمكافآت
- **العضويات** — الخطط (المخطط جاهز؛ دورة الفوترة لاحقاً)

### 8. الذكاء الاصطناعي (استشاري فقط)

- `AiManager` + تجريد للمزودين، وتدهور رشيق بدون بيانات اعتماد
- نقاط نهاية: البحث عن خدمة، بناء موجز من المتطلبات، تلخيص المحادثات — اقتراحات الذكاء الاصطناعي لا تعدّل البيانات المعاملاتية أبداً

### 9. المنصة والبنية التحتية

- **RBAC** — 24 دوراً، وأكثر من 70 صلاحية دقيقة، وصلاحيات مؤسسية محددة النطاق، ووسيط `permission:`
- **المصادقة** — تسجيل موجّه بالغرض، دخول، جلسات (عرض/إبطال)، قفل بعد المحاولات، إعادة تعيين كلمة المرور، و**تحقق ثنائي TOTP RFC-6238** إلزامي للحسابات المميزة
- **سجل التدقيق** — الفاعل، قبل/بعد، IP، ومتصفح المستخدم للإجراءات الحساسة
- **المواقع** — شجرة مواقع إندونيسيا (بلد←حي)، 15 مقاطعة / 33 مدينة مهيأة، وعناوين العملاء بإحداثيات
- **تجريد البحث والجغرافيا** — `SearchProviderInterface` و`GeoServiceInterface` (هافرساين + فلتر نطاق)
- **الوسائط** — `MediaService` (MIME حقيقي + بايتات سحرية + حد حجم)، ومكوّن `service-image` مع بديل أيقونة الفئة
- **PWA** — ملف manifest + عامل خدمة (تخزين مؤقت للثوابت فقط؛ API/الإدارة عبر الشبكة)، قابل للتثبيت
- **الصحة والمراقبة** — `/api/v1/health` (قاعدة البيانات+Redis) + `/up`، وسجلات منظمة
- **التصلّب** — ترويسات أمان، محددات معدل (api/auth/webhook)، غلاف أخطاء دون كشف داخلي، CSRF، تهريب XSS، وفحوص ملكية على كل المسارات
- **المجدول** — انتهاء صلاحية الطلبات، توليد التكرارات، وتنظيف TTL (طلبات التكلفة والعروض)

### 11. واجهة API‏ (`/api/v1` — 150 نقطة نهاية)

`auth` (تسجيل/دخول/2FA/جلسات/كلمة المرور) · `catalog` (الفئات/الخدمات/المواقع، إدارة خدمات الشريك) · `addresses` · `orders` (عرض سعر/إنشاء/إلغاء/تأكيد/دخول/قرار التكلفة الإضافية) · `field` (العروض، قبول/رفض، في الطريق/وصل/دخول/بدء عمل/أدلة/مواد/تكلفة إضافية/تقديم) · `chat` (مباشرة، لكل طلب، رسائل، قراءة، إبلاغ) · `notifications` (+التفضيلات) · `projects` (قرار العرض/العقد/تمويل-موافقة-تعديل-صرف المراحل) · `partner/deals` (المشاريع، العروض، العقود، المراحل، سجلات العمل) · `rfqs` + `quotations` · `reviews` + `disputes` · `corporate` (المنظمات، الموظفون، السياسة، الطلبات، الموافقة، التحويل) · `ai` · `cms`/`blog`/صفحات SEO · تذاكر `support` · `partner` (الملف، التحقق، المهارات، المستندات، مناطق الخدمة، الاستلام، الأعضاء) · `payments` · `health`

تصميم **API أولاً**: يمكن لـ Flutter/الجوال الوصول إلى النطاق كاملاً دون تكرار منطق.

## البيانات التجريبية

تأتي جاسابيديا مع **بيانات تجريبية بجودة الإنتاج** لتشعر واجهة المتجر ومركز الشركاء ومركز قيادة الإدارة وسوق المشاريع وطلبات الأسعار وجاسابيديا للأعمال كأنها سوق حي — وليس تثبيتاً فارغاً.

```bash
# مجموعة البيانات التجريبية الكاملة (الافتراضي):
#   10,000 خدمة نشطة | 2,500 مقدم خدمة | 5,000 عميل
#   3,000 طلب | 500 مشروع | 500 RFQ | 7,000 تقييم | 50 مؤسسة
php artisan jasapedia:seed-demo

# حذف الصفوف الموسومة is_demo فقط، ثم إعادة البذر من الصفر:
php artisan jasapedia:seed-demo --fresh-demo

# حجم مخصص (لبيئات CI / الأجهزة الضعيفة):
php artisan jasapedia:seed-demo --services=210 --providers=21 --customers=40 --orders=25 --reviews=15 --fresh-demo
```

> ⚠️ **لا تُشغّله في الإنتاج أبداً.** يرفض الأمر العمل عندما `APP_ENV=production` ما لم يُمرَّر `--force` **مع** تأكيد تفاعلي. البيانات موسومة `is_demo=1` في كل الجداول الرئيسية — `--fresh-demo` يحذف صفوف العرض فقط؛ بيانات الإنتاج والعملاء الحقيقية لا تُمس أبداً. تشغيل الأمر مرة ثانية بدون `--fresh-demo` **مرفوض** (حماية عدم التكرار).

**الشروط المضمونة في مجموعة البيانات التجريبية:**

- **10,000 خدمة نشطة** موزعة بدقة على **21 فئة** (توزيع largest-remainder، مع تأكيد داخل البادئ)
- عناوين/أوصاف/أسعار باللغة الإندونيسية **خاصة بكل فئة** من قاموس (لا نصوص عشوائية)، وروابط فريدة
- أسعار IDR صحيحة ضمن نطاقات واقعية لكل فئة (مثلاً: التنظيف 50 ألف–2.5 مليون؛ التجديد 500 ألف–250 مليون؛ الإنشاءات حتى 1 مليار)
- الموردون: 60% أفراد/مستقلون، 30% موردون، 10% شركات (منظمات + أعضاء)، 75% موثقون؛ **شارات المستوى تُحسب من البيانات** (المنجزات + التقييم) وفق المنطق القائم — لا شارات وهمية
- مواقع واقعية مركزة في جابوديتابيك وباندونغ وسورابايا وغيرها (الإحداثيات = اهتزاز حول مراكز مدن صحيحة من LocationSeeder)
- الطلبات: مجموعة مكتملة مالياً تمر **عبر خدمات النطاق الحقيقية** (`OrderService` ← خطاف ويب sandbox لـ `PaymentService` ← `OrderStateMachine` ← `SettlementService` ← `RefundService`/`WithdrawalService`) — **دفتر الأستاذ يبقى متوازناً**، Σ المدين = Σ الدائن
- التقييمات: للطلبات `completed|settled|closed` فقط (تقييم واحد/طلب)، 5★ ~70% / 4★ ~21% / 3★ ~6%، والتقييمات بالأبعاد تتبع `Category.config.review_dimensions`، وتقييم الشريك يُعاد حسابه من المجاميع
- سوق المشاريع + العروض + العقود + المراحل؛ RFQ + عروض الأسعار (مفتوح/مغلق/مُسند)؛ المؤسسات (فروع، إدارات، مراكز تكلفة، سياسات موافقة، CSR + PO)
- الوسائط: مخزون صور محلي حتمي لكل فئة (360 ملفاً: أغلفة WebP بمقاس 1200×800، صور رمزية SVG للموردين، لافتات فئات — بلا تنزيل شبكي ولا روابط خارجية)؛ 100% من الخدمات لها غلاف، 70% لديها صورتي معرض فأكثر، ولكل مورد صورة رمزية
- الصفحات الرئيسية/الاستكشاف/الإدارة ممتلئة فوراً: الفئات، الخدمات الشائعة، الموردون الموثقون، التقييمات، المدونة، وبيانات SEO
- كل الإدراجات على دفعات من **500 صف** (لا 10,000 سجل عبر HTTP أبداً)، بذر حتمي (`mt_srand`)، والوسائط تُحل عبر `MediaService::url()`
